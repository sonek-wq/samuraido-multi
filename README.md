# 侍道 ― SAMURAIDO ― フレンド対戦版

ブラウザで遊べる、スーパーファミコン風ドット絵の2D剣戟アクションゲームの、オンライン対戦対応版です。
一人用の「六番勝負」に加えて、離れた友人とルームコードで1対1の対戦ができます。

`index.html` 1ファイルで完結しています。画像・音声ファイルは使わず、Canvas と Web Audio API で描画・合成しています。
通信には [PeerJS](https://peerjs.com/) を CDN から読み込んで使っています。

## 遊び方

GitHub Pages で公開したページを開き、タイトル画面で ↑↓ を押して遊び方を選びます。

- **一人で遊ぶ　六番勝負**：6人のCPUと順に戦います。一度でも敗れると第一戦からやり直しです。
- **フレンド対戦　部屋を作る**：5文字の部屋コードが表示されます。そのコードを相手に伝えてください（C キーでコピーできます）。
- **フレンド対戦　部屋に入る**：相手から聞いた部屋コードを入力（貼り付けも可）して Enter を押します。

対戦では、部屋を作った人が左（青）、部屋に入った人が右（赤）の侍を操作します。
決着後は、両者が Z を押すと再戦します。Esc で対戦から抜けます。

| キー | 操作 |
|---|---|
| ← → | 前進・後退（相手との位置関係で自動判定） |
| Z | 攻撃 |
| X | ガード（攻撃が当たる直前に押すと「弾き（パリィ）」） |
| P | 一時停止（一人用のみ） |
| Esc | タイトルへ／対戦から抜ける |

## システム

- **体力（黄）**：0になると敗北。
- **体幹（赤）**：攻撃を受けたり、ガードしたりすると減り、何もしなければ回復します。0になると「体幹崩し」で一定時間動けなくなり、その間に斬られると致命の一撃（大ダメージ）を受けます。
- **弾き**：攻撃が当たる直前にガードを押すと、ダメージを無効化し、攻撃した側の体幹を大きく削ります。押しっぱなしや連打では弾きになりません。
- **相子**：互いの攻撃が同時にぶつかると、両者の体幹が削れて弾き返されます。
- **画面端**：壁を背負うと後退できず、受ける体幹ダメージも増えます。

## 通信のしくみ

- ブラウザ同士を WebRTC で直接つなぎます。最初に相手を見つけるときだけ、PeerJS が無料で公開している接続用サーバーを使います。
- 毎フレーム「入力」だけを送り合い、両者が同じ計算をして同じ試合を再現します。
- 通信の遅れには**ロールバック方式**で対応しています。相手の入力がまだ届いていないときは「直前と同じ入力」と予測して先に進め、予測が外れていたら、そのフレームまで巻き戻して計算し直します。
- 入力遅延は2フレーム、予測で先行できるのは最大10フレームです。それ以上遅れると、相手の入力が届くまで少し待ちます。
- 両者の試合状態は1秒ごとに照合しています。食い違いが見つかった場合は、画面左下に表示されます。
- 会社や学校のネットワークなど一部の環境では、直接つながらないことがあります。PeerJS 標準の中継サーバーで補えることもありますが、確実ではありません。

## 調整

ゲームのパラメータ（移動速度・フレーム数・ダメージ量・CPUのAIなど）は、`index.html` のスクリプト冒頭に定数としてまとめてあります。
通信まわりの設定は、スクリプト中の `NET` にまとめてあります（入力遅延 `INPUT_DELAY`、最大巻き戻し `MAX_ROLLBACK` など）。

### 開発・テスト用

URL に `?peerhost=127.0.0.1&peerport=9000` を付けると、公開サーバーの代わりに手元の PeerJS サーバー（`npx peerjs --port 9000` など）に接続します。
